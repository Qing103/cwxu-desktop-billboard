# 视觉设计

本应用是无锡学院主题的非官方桌面看板，未获得学校授权或背书。没有确认的校徽、VI 手册或品牌授权时，不使用官方标识；界面以“锡”字文字标记和中性蓝绿色作为临时视觉方向。

## 布局

- 保留 420×40 透明置顶桌面岛，点击后打开独立的 Fluent 工作区窗口。
- 工作区采用紧凑的桌面信息布局，避免营销页式大标题和宽屏数据墙。
- 主看板突出当前日期、校务数据接入状态和本机日程。
- 教务、校园卡、宿舍和网络模块在接入学校官方数据源前始终显示“待接入”。
- 日程周视图清晰呈现时间轴，支持本机新增和编辑。

## 颜色与状态

- 使用蓝绿色作为交互强调色，浅色和深色主题均保持足够对比度。
- “待接入”用中性状态呈现，不使用告警红色，也不伪装成正在同步。
- 使用无锡学院校训“尚德笃行 · 求是鼎新”作为文字辅助信息，不将其写成应用背书。
