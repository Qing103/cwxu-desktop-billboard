这是基于 [nidong](https://github.com/sapphire-xu/nidong) 桌面看板改造的**非官方**无锡学院桌面看板。未获得学校授权或背书，与无锡学院信息化部门无关。

## 设计目标（详情可见[nidong](https://github.com/sapphire-xu/nidong)）

看板式信息整合：校园卡、网费、电费和今日课程收在同一块看板上。贴顶岛只留一节课、倒计时和余额警告。
• 课程日程触手可及：登录后获取整学期课表，每天自动同步一次。日程和课程显示在同一条周视图上，可提醒。自定义日程存在这台电脑上。
• 校园网自动登录，安全快捷：可以在未联网、开机、离开指定网络，或自己连上校园网时连接并登录。密码只在学校登录页的证书核对通过后加密发送。同名网络对不上证书时，密码不会提交。
• 校园网免流量文件分享：发送者可通过泥洞创建文件分享临时服务，接收者通过电脑/手机浏览器访问即可下载文件，要求双方都登录校园网，此过程不消耗校园流量，快捷方便。
• 账单：校园卡本月花费和当日流水，以及网费计费说明。卡、网、电大约 20 分钟自动刷新。
• 宿舍电费：在设置里填房间码后显示余量。每天约 23:00–8；00 电费系统经常连不上，同步失败就显示上次缓存。
• 离线：没网时若上次没退出登录，窗口直接进主页，并提示「离线状态」。
• 跳过登录：跳过登录仍能使用无需登录的功能。
• 任意门：直达官方网站和民间信息聚合网站。学校站点在校园网直连，人在校外时改走 WebVPN。校园网网关只能在校园网里开。浏览器不带看板自己的登录状态。
• 校内 / 校外：校园网直连一卡通和教务；校外先走学校 WebVPN 再拉数据。
• 本机凭据：一号通学号密码进 Windows 凭据管理。关掉「记住密码」会删掉密码。
• 单实例：已经在跑时再打开，会叫出岛并打开窗口。

## 当前状态

目前完成品牌、桌面岛和看板界面适配，可使用本机日程、周视图、提醒、主题和桌面岛设置。首次进入时可创建本机昵称并保存教务账号；密码只存入操作系统凭据库，不写入普通设置文件。课程周视图已采用用户提供的无锡学院官方 1–11 节作息；已添加学校官网、学生教务系统登录页及个人课表查询页入口，并为已知课程字段准备了解析映射。由于教务登录流程、课表响应容器和安全会话接入仍未确认，自动登录和同步暂未启用；统一身份认证、校园卡、宿舍及网络数据接口也尚未接入，相关卡片会显示“待接入”。
项目不会把东北大学登录或数据接口当成无锡学院接口使用。登录、验证码、账单、课表同步和校园网自动登录均已禁用；启动时会清理学校服务快照，不读取旧应用的密码凭据。自动更新也已关闭，安装身份与上游版本隔离。

## 运行环境

- Windows 桌面应用
- Tauri 2 + Rust
- React 18 + TypeScript + Fluent UI
- Node.js 和 Rust 工具链
```powershell
npm ci
npm start
```
`npm start` 启动 Tauri 开发模式。打包使用 `npm run tauri build`。

## 项目结构

- `ui/src/App.tsx`：屏幕顶部 420×40 桌面岛
- `ui/src/desk/`：看板、日程、学校官网、设置和关于页面
- `ui/src/agenda.ts`、`ui/src/desk/pages/Schedule.tsx`：本机日程与周视图
- `src-tauri/src/agenda.rs`：本机日程文件读写
- `src-tauri/src/lib.rs`：Tauri 命令、窗口、托盘和本地设置
现有 Rust 仓库仍包含上游项目的历史学校客户端代码；本版本启动路径不创建学校客户端，登录和同步命令均被拒绝，学校入口命令只允许打开无锡学院官网、教务登录页和用户提供的个人课表查询页。

## 后续接入校园数据

已确认的个人课表查询页只作为官方网页入口使用，不代表看板已取得课表数据接口。只有核实请求方法、参数和响应结构后，才继续适配课表同步；不要猜接口、复用其他学校的身份认证流程，也不要把账号密码发送给自建服务。
